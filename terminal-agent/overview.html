Project Overview

This project is an investigation into AI-powered terminal agents that can reason over software engineering tasks, use tools, execute commands, modify files, and work through multi-step workflows.

Why I'm Building This

My goal is to understand what it actually takes to build, evaluate, and improve production-quality terminal agents.
