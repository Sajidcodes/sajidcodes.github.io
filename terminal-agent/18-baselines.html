Baselines

The number every later experiment has to beat, and why I measured it three times.

In short
  • Reference baseline: 84.4% ± 1.9% on the 30-task local suite (gpt-4o, 3 runs).
  • Cost: about $0.016 per task.
  • Hard debugging tasks are the weak spot: 70%, against 97% on file tasks.

Why I don't call 70% → 84% an improvement

The code changed between those two runs, and one is a single run. They're two separate measurements, not an experiment. Every comparison on this site uses the 3-run number, with the code version recorded in summary.json.

What the Tiers Tell Me

File tasks are nearly solved. Debugging is where the agent loses points: it has to find a bug, not just follow an instruction. Any change I make should move tier 3 without hurting tier 1. That's how I judge the experiments in section 19.
