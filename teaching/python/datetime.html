Working with Dates and Times in Python

Why do we need dates and times?

Many programs need to know when something happened.

For example:

  • When was an assignment submitted?
  • What time did a program start?
  • When was a file created?
  • What is today's date?
  • How many days have passed since an event?

Python provides the datetime module for working with dates and times.

1. Import datetime

We can import the datetime class like this:

Now Python knows that we want to use the datetime class.

2. Get the current date and time

The now() method gives us the current date and time.

You might see something similar to:

2026-10-05 09:42:18.532741

The exact result will be different every time because it represents the moment when your program runs.

3. Understanding the result

A datetime object contains several pieces of information.

For example:

2026-10-05 09:42:18

can be thought of as:

2026   → year
10     → month
05     → day
09     → hour
42     → minute
18     → second

We can access each piece separately.

4. Getting the year

Example output:

2026

The dot operator lets us access information stored inside the datetime object.

5. Getting the month and day

Example:

10
5

So:

current.month

means:

Get the month stored in current.

And:

current.day

means:

Get the day stored in current.

6. Getting the time

We can also retrieve the hour, minute, and second.

For example:

9
42
18

8. Creating a specific date and time

datetime can also represent a date and time that we choose ourselves.

The general pattern is:

datetime(year, month, day, hour, minute, second)

For example:

Output:

2026-12-15 10:30:00

This is useful when a program needs to work with a specific date rather than the current moment.

Common mistake

A common beginner mistake is confusing the datetime class with a datetime object.

Here:

  • datetime is the class we imported.
  • datetime.now() creates a datetime object.
  • current refers to that object.
