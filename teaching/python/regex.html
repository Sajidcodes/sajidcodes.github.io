0. Introduction

Programs often need to determine whether text follows a pattern:

  • a value contains only digits
  • a username follows a particular format
  • a phone number has the expected structure
  • an email address appears in a piece of text
  • a value contains exactly 5 digits

A regular expression (regex) is a pattern that describes what text we are looking for.

Pattern Meaning Matches Doesn't match
\d one digit 0, 5, 9 a
\d{3} exactly three digits 123, 007 12, abc

Python provides regex tools through the built-in re module.

1. Why Do We Need Regular Expressions?

A program asks for a 6-digit student ID. Users might enter 123456, 123, ABC123, or 12-3456. Instead of writing many if statements, a regex describes the pattern directly: r"\d{6}".

Normal string thinking Regex thinking
"What characters are here?" "Does this text follow this pattern?"

5. Why Do We Write r"\d"?

The r prefix makes a raw string: backslashes are kept as-is and passed to the regex engine.

Important: the r is part of Python string syntax — it is not part of the regular expression.

44. The Five Functions to Remember

Function Purpose
re.search(pattern, text) find a pattern anywhere
re.match(pattern, text) look for a pattern at the beginning
re.fullmatch(pattern, text) require the entire string to match
re.findall(pattern, text) find all matches
re.sub(pattern, replacement, text) replace matches

45. A Useful Mental Model — Build Left to Right

Goal: exactly three digits, a dash, then two digits.

\d            one digit
\d{3}         three digits
\d{3}-        ... then a dash
\d{3}-\d{2}   ... then two digits

46. Think of Regex as a Language

\d       → digit
+        → one or more
{3}      → exactly three
[ABC]    → A, B, or C
|        → OR

Combine the pieces: [A-Z]\d+ = an uppercase letter followed by one or more digits.

47. A More Complex Example — Product Code ABC-1234

Requirements: three uppercase letters, a hyphen, four digits.

[A-Z]{3}            three uppercase letters
[A-Z]{3}-           ... a hyphen
[A-Z]{3}-\d{4}      ... four digits

52. ✏️ Practice: Predict the Match

text = "Room 204"
result = re.search(r"\d+", text)
if result:
    print(result.group())

What is printed? A. Room B. 20 C. 204 D. Room 204

Make your prediction, then run the cell below.

Answer **C** — `\d+` means one or more *consecutive* digits, so the match is `204`.

53. ✏️ Practice: search() vs fullmatch()

text = "ID: 12345"
result = re.fullmatch(r"\d+", text)
print(result)

A. 12345 B. A match object C. None D. An error

Answer **C** — the entire string `ID: 12345` is not composed only of digits.

Write a pattern for each, then test it with test(pattern, [...]):

  2. A course code like CIS-108 or CIS-105 (3 uppercase letters, hyphen, 3 digits)
  3. Extract every hashtag from "Loving #Python and #DataScience at #PCCC" using findall

Solutions 
test(r"\d{5}(-\d{4})?", ["07102", "07102-1234", "0710", "07102-12"])
test(r"[A-Z]{3}-\d{3}", ["CIS-108", "CIS-105", "cis-108", "CIS108"])

print(re.sub(r"!+", "!", "Wow!!! Amazing!!"))
