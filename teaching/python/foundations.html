Python Programming

0. Foundations of Programming

Before writing significant Python programs, learn what programming is, how programs work, and how programmers approach problems.

0.1 What Is Programming?

1. What Is a Computer Program?

Beginner idea: A computer program is a set of instructions that tells a computer what to do.

Think of a program like a recipe.

  1. Get two eggs.
  2. Crack the eggs.
  3. Mix them.
  4. Cook them.

A computer program does something similar:

  1. Get some information.
  2. Process the information.
  3. Produce a result.

Example — Calculator

Get 10 Get 5 Add them Display 15

4. Interpreters vs. Compilers

Beginner idea: Both interpreters and compilers help translate programming languages into something the computer can execute.
Interpreter: Code → Process / execute Compiler: Code → Translate → Executable / program → Run

Python is commonly described as an interpreted language because Python programs are executed through the Python interpreter.

6. Algorithms and Instructions

An algorithm is a sequence of steps used to solve a problem.

You already use algorithms in everyday life.

Example — Making Toast

  1. Get bread.
  2. Put bread in toaster.
  3. Start toaster.
  4. Wait.
  5. Remove toast.

Example — Finding the Largest Number

Suppose we have: 

5, 12, 7
  1. Start with 5 as the largest.
  2. Compare 12 with 5.
  3. 12 is larger → largest = 12.
  4. Compare 7 with 12.
  5. 7 is not larger.
  6. Answer = 12.

0.2 The Software Development Process

Programming isn't simply:

Open Python → Start typing

Professional programming follows a process.

Problem ↓ Requirements ↓ Algorithm ↓ Pseudocode / Flowchart ↓ Implementation ↓ Testing ↓ Debugging ↓ Documentation ↓ Maintenance

1. Problem Definition

First, determine what problem you are trying to solve.

Don't immediately write code.

Example — Grade Calculator

Students need a program that calculates their final grade.

Example — Temperature Converter

Users need a program that converts Fahrenheit temperatures to Celsius.
Students should be able to: State the problem clearly before programming.

2. Requirements

Requirements describe what the program needs to do.

Grade Calculator

Input
  • Homework grade
  • Exam grade
Process
  • Calculate average
Output
  • Final grade

Shopping Program

Input
  • Product price
  • Quantity
Output
  • Total cost

Login Program

Input
  • Username
  • Password
Output
  • Login successful
  • OR Login failed
Students should be able to: Identify the inputs and outputs required by a problem.
