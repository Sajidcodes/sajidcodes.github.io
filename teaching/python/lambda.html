Lambda functions in Python

A lambda is a tiny one-line function you write right where you need it. Its most common job: telling sorted() what to sort by.

Pick a sort rule and watch the class reorder. The highlighted column is what the lambda hands to Python.


    

      

        
First (t[0])Last (t[1])Score (t[2])Sort key

        
      

    

  


  
1The problem

  
Each student is a tuple: (first name, last name, score).

  
students = [
    ("John", "Smith", 96),
    ("Susan", "King", 76),
    ("Kim", "Yao", 99)
]

sorted(students)
[('John', 'Smith', 96), ('Kim', 'Yao', 99), ('Susan', 'King', 76)]

  
Plain sorted() compares the first value, so it sorts by first name. What if we want score or last name instead?


  
2Regular function vs. lambda

  

    
Regular
def area(radius):
    return radius * radius * math.pi

    
Lambda
lambda radius: radius * radius * math.pi

  

  
Same job, shorter. No def, no return. The expression after the colon is returned automatically.

  
lambda parameters: expression

  
import math

area_lambda = lambda radius: radius * radius * math.pi
area_lambda(5)
78.53981633974483


  
3The key argument

  
sorted(data, key=some_function)

  
key answers one question: for each item, what value should I sort by?

  

    
IndexValue

    
      
t[0]first name

      
t[1]last name

      
t[2]score

    
  


  
4Sort by last name

  
lambda t: t[1] means "give me the last name."

  
sorted(students, key=lambda t: t[1])
[('Susan', 'King', 76), ('John', 'Smith', 96), ('Kim', 'Yao', 99)]

  
Here is what Python sees. The lambda runs on each student and returns a sort value:

  
for t in students:
    print(t, "→", t[1])
('John', 'Smith', 96) → Smith
('Susan', 'King', 76) → King
('Kim', 'Yao', 99) → Yao

  
The data does not change. The lambda only decides where each student goes.


  
5Sort by score

  
# low to high
sorted(students, key=lambda t: t[2])
[('Susan', 'King', 76), ('John', 'Smith', 96), ('Kim', 'Yao', 99)]

  
# high to low
sorted(students, key=lambda t: t[2], reverse=True)
[('Kim', 'Yao', 99), ('John', 'Smith', 96), ('Susan', 'King', 76)]

  
The lambda picks what to sort by. reverse=True picks the direction.


  
6Sort by two things

  
Return a tuple: (main rule, tie-breaker).

  
students = [
    ("John", "Smith", 96),
    ("Susan", "King", 76),
    ("Kim", "Yao", 99),
    ("Qi", "Yao", 79)
]

sorted(students, key=lambda t: (t[2], t[1]))
[('Susan', 'King', 76), ('Qi', 'Yao', 79), ('John', 'Smith', 96), ('Kim', 'Yao', 99)]

  
Python sorts by the first value. Only when those tie does it look at the second.


  
7Mixed directions

  
Score high to low, but last name A to Z? Put a minus sign on the number.

  
sorted(students, key=lambda t: (-t[2], t[1]))

  
95 → -95
88 → -88
72 → -72

  
Python sorts smallest first: -95, -88, -72. That puts scores 95, 88, 72 in order, highest first. Try it in the demo at the top: Carlos and Fatima tie at 95, so last name breaks the tie.

  
The minus trick only works on numbers. You can't put - in front of a string.


  
8Common mistake

  
t[2] does not mean "the third student." It means: for the current student t, take the value at index 2.

  
("John", "Smith", 96)
                  ↑
                 t[2]  →  96


  
9More than one input

multiply = lambda x, y: x * y

10Lambda or def?

  

    
Use lambda whenUse def when
